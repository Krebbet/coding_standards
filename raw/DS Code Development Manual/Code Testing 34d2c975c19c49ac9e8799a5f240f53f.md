# Types of Testing Overview

There are three main types of testing: Unit tests, integration tests, and E2E tests. 

- Unit tests help identify any errors that arise on individual components of an application by testing functions against input/output pairs that are known to be correct. Integrations tests work in the same way, but test the application on a fuller scale.
- Integration tests require many smaller components to come together to get a correct result. Just like a unit test might have known inputs/outputs for small components an integration test might have known inputs/outputs for a larger component comprised of these unit tested components.
- End-to-end testing is different from the other two types of testing in that it tries to replicate the full use case of an application from an end-users perspective. This generally involves a person sitting down and running through each different feature offered by the application, whereas the other tests are usually automated.
