# Learning Resources

This page serves as a collection of resources for learning how to improve the quality and cleanliness of your code

DISCLAIMER: Please make sure you are familiar with the [notion pages](../Writing%20Code%20a80c65f8b839461797206892831889f6.md) on our style and design standards before taking advice from the external resources below. The links below are just meant to be helpful resources for improving your coding skills, they are not SFL standards. You should always default to following SFL standards if there is any conflicting advice

# Textbooks
