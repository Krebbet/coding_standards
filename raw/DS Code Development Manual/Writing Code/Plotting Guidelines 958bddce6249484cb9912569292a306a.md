# Plotting Guidelines

The main goal when creating materials for client presentation is to ensure successful communication so that clients can quickly and effortlessly understand the presented information. To this end, plots are useful for summarizing insights as they are typically easier than text to quickly assimilate information. 

Here, we describe some general guidelines for creating good plots.
