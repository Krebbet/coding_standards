# After plot creation

After creating plots, improve their utility during presentation or within a report. Plots are landmarks within the larger landscape of materials provided to clients. Ensure they are showcased well within the larger landscape.

# Clear Explanation

Plots and tables should always be referenced in the text and explained to some extent. This should include:

- Explanation of how to understand the figure
- Statement of the figure’s results
- Describe the “so what” from the client point of view (e.g., how this EDA graph will affect decisions made in the next phase of modeling, for example).

# Clear Layout

Within a report, exhibits should fill the full width of the page when possible. Avoid leaving large amounts of white space between or on the sides of exhibits.

# Internal Consistency

For internal consistency, use SFL Conventions for Plots:

- Plot titles should use sentence case (see point 1 of section 6.2 in [SFL style guide](https://docs.google.com/document/d/1VhoDz-LVqXYl44jPlkYRKTT_ARQ1BTVmCXD9Vj3Pgk8/edit)).
- All plots and tables within a report should be labeled as and referred to as "Exhibits" using ascending numbering starting from 1 (see section 2.3 in [SFL Style Guide](https://docs.google.com/document/d/1VhoDz-LVqXYl44jPlkYRKTT_ARQ1BTVmCXD9Vj3Pgk8/edit?usp=sharing)).
- Plots should be referenced using parentheses at the end of a sentence (see point 3 of section 2.3 in [SFL Style Guide](https://docs.google.com/document/d/1VhoDz-LVqXYl44jPlkYRKTT_ARQ1BTVmCXD9Vj3Pgk8/edit?usp=sharing))
    
    ```
    # Do not do this:
    Exhibit X shows that the variable A is normally distributed.
    
    # Instead, do this:
    Variable A is normally distributed (Exhibit X).
    ```
    
- In reports, remember to link all in-text references to the bookmarked exhibit.
