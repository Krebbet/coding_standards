# PEP8 is the Default Standard

Level: Notebook, Repo
Constraint: Hard
Last Edit: June 17, 2024 3:00 PM
Project Types: GA, MVP, POC

When nothing else on this page applies, [PEP8 standards](https://peps.python.org/pep-0008/) should be adhered to. Our GitHub actions will request you format your code to this standard using black.
