## Double Inverted Commas for Strings

Double inverted quotes should be the default for strings. 

Exceptions may be acceptable for when the double quotation is actually required in the string.  

**Bad:**

```python
x = 'Hello Mike'
```

**Good:**

```python
x = "Hello Mike"
```
