# Code Review Checklist

As code undergoes review, please remember these methods for a productive and professional process: [Code Review Interaction Guidelines](Code%20Review%20Interaction%20Guidelines%208b71bad4e76e4691abd6953b834f75f2.md) 

Resolve any failures from the Pull Request Actions in GitHub. Exceptions are only made for Markdown-related actions.

- [ ]  [Pull Request Actions](../Version%20Control%20(Git%20&%20GitHub)/GitHub%20Actions/SFL-Template%20GitHub%20Actions%208d40d0e9bb364038a9cdbc8447897665.md) → “Pull Request Actions”

Developers and reviewers should align the code to the following during code review.

- [ ]  [Code Standards](../Writing%20Code/Code%20Standards%20bb20e0f77b0f4d52b8d416a19ef1699b.md) and/or [DE Code Guidelines](https://www.notion.so/DE-Code-Guidelines-01bfcffdfea5433e9fe08c3c426ad839?pvs=21)
- [ ]  [Design Checklist](../Writing%20Code/Design%20Checklist%20a8c93611bc9c44ed8e71c8bc4033812e.md)

Outstanding FIXMEs and TODOs should be added to the Issue Tracker

- [ ]  [Issues Standards](../Version%20Control%20(Git%20&%20GitHub)/Issues%20Standards%2090450972bfa8482bafbe16a424105b99.md)

For projects with a 4-week or longer timeline, implement Code Tests to the required level

- [ ]  [Code Testing](../Code%20Testing%2034d2c975c19c49ac9e8799a5f240f53f.md)

For projects with client-facing plots and notebooks, the following guidelines may be relevant

- [ ]  [Jupyter Notebook Guidelines](../Writing%20Code/Jupyter%20Notebook%20Guidelines%20d8d4eab8446a4aa586026326d9cf0689.md)
- [ ]  [Plotting Guidelines](../Writing%20Code/Plotting%20Guidelines%20958bddce6249484cb9912569292a306a.md)
