# PyTest Crash Course

This is a landing page for all of the tutorial materials on unit testing. 

This collection of notion pages is geared towards readers that have little to no experience with unit testing. The first sub-page gives a basic introduction to unit testing and PyTest along with some basic syntax suggestions and a basic example. The following page walks through some important concepts in unit testing and PyTest such as parameterization, mocking, and fixtures. Finally, the third page discusses some more practical considerations in unit testing, including running tests in an IDE

**NOTE:** If you already have experience with unit testing, please see the [unit testing guidelines](Unit%20and%20Integration%20Testing%20Guidelines%209c263c529f5e4fceadacd1becb3c5a0c.md) and the [unit testing best practices](https://www.notion.so/Code-Testing-Best-Practice-894bc57c55fb463a90622260ef56823d?pvs=21) pages
